FRANKLYN'S PORTFOLIO WEBSITE

HTML PAGES AND THEIR SEPARATE CSS FILES
- index.html uses home.css
- about.html uses about.css
- projects.html uses projects.css
- skills.html uses skills.css
- education.html uses education.css
- contact.html uses contact.css
- script.js is shared by all pages

Each page has its own CSS file. The CSS contents are initially the same to preserve the current design. You can customize one page without changing the others.

HOW TO USE
1. Extract this ZIP file.
2. Put your profile photo in this folder and name it Profile.jpg.
3. Open index.html to preview the website.
4. Edit the school, contact details, social links, projects, and skill levels so they are accurate.
5. Upload all files to your GitHub repository, keeping index.html in the root folder.

The contact form is a visual template and needs a form service or backend before it can send messages. Replace project placeholders with your actual work.
